# DayBreak Engine V1.0

A GoldHEN plugin for **Call of Duty: Black Ops III** multiplayer on PS4 (CUSA02290).

## Download

Get `DayBreak.sprx` from the [latest release](../../releases/latest).

## Install

1. Copy `DayBreak.sprx` to `/data/GoldHEN/plugins/`.
2. Add it to `/data/GoldHEN/plugins.ini`:
   ```ini
   [CUSA02290]
   /data/GoldHEN/plugins/DayBreak.sprx
   ```
3. Start the game with plugins enabled in GoldHEN.

## Controls

| Input | Action |
|---|---|
| L1 + D-pad Right | Open / close the menu |
| L1 / R1 | Previous / next tab |
| D-pad Up / Down | Move |
| D-pad Left / Right | Change a value |
| X | Select |
| O | Back / close |

## Features

| Where | Tab | Options |
|---|---|---|
| Match | Aimbot | Snap and Silent aim, activation, presets, targets, aim zone, smoothing and jitter, triggerbot, anti aim |
| Match | Visuals | ESP filters, boxes and skeleton, player info with weapon names, dropped items, chams and wallhack, colors |
| Match | HUD | Info overlay, watermark, health, aim visuals, compass |
| Match | Mods | No Recoil, No Spread, FOV changer |
| Lobby | Stats & Unlocks | Unlock All, cryptokeys (add and reset), prestige, level, combat stats, medals |
| Lobby | Name | Name, colors, rainbow name, clan tag |
| Both | Style | Menu themes and layout, save config |

**Save Config** (Style tab) keeps your settings. The name and clan tag choices are not saved.

A stuck "retry or cancel" cryptokeys prompt is cleared with **Stats & Unlocks > Cryptokeys > Reset Cryptokeys**.
